### Example 1 — YoY percentage change + anomaly flag

Task: "Tính % thay đổi YoY theo region, đánh dấu vùng có tăng trưởng bất thường bằng IQR"

Input df columns: region, rev_2024, rev_2023

Output:
import pandas as pd
import numpy as np

df = df.copy()
df = df.dropna(subset=['rev_2024', 'rev_2023'])
df['yoy_pct'] = ((df['rev_2024'] - df['rev_2023']) / df['rev_2023'] * 100).round(2)

Q1 = df['yoy_pct'].quantile(0.25)
Q3 = df['yoy_pct'].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

df['is_anomaly'] = ((df['yoy_pct'] < lower) | (df['yoy_pct'] > upper))
df

### Example 2 — Statistical summary + filtering

Task: "Tính trung bình và độ lệch chuẩn overtime_hours theo department, lọc những phòng có avg > 20h"

Input df columns: department, overtime_hours

Output:
import pandas as pd

df = df.copy()
df = df.dropna(subset=['overtime_hours'])

summary = (
    df.groupby('department')['overtime_hours']
    .agg(avg_overtime='mean', std_overtime='std', count='count')
    .round(2)
    .reset_index()
)

result = summary[summary['avg_overtime'] > 20].sort_values('avg_overtime', ascending=False)
result

### Example 3 — Use scipy.stats with explicit import

Task: "Tính z-score của bonus_ratio theo level và đánh dấu outlier z_score > 3"

Input df columns: name, level, bonus_ratio

Output:
import pandas as pd
import numpy as np
from scipy import stats

df = df.copy()
df = df.dropna(subset=['level', 'bonus_ratio'])

df['z_score'] = (
    df.groupby('level')['bonus_ratio']
    .transform(lambda s: stats.zscore(s, nan_policy='omit'))
)
df['z_score'] = df['z_score'].fillna(0.0).round(3)
df['is_anomaly'] = (df['z_score'].abs() > 3)
df
